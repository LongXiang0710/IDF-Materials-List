# IDF 材料表助手

一个无需安装、全程离线运行的 ISOGEN IDF 材料表解析工具。

## 使用

Windows 下直接双击项目根目录的 `启动IDF材料表助手.bat` 即可打开本地小程序；也可以直接双击 `dist/index.html`，或用任意静态文件服务器打开 `dist` 目录。可一次选择或拖入一个或多个 `.idf`、`.txt`、`.dat` 文件，工具会逐文件解析后合并材料表，并可导出 Excel（XML `.xls`）或 UTF-8 CSV。

导入多个文件后，Excel 可选择“合并为一个 Excel”或“每个 IDF 分别导出”。分别导出时，每个文件独立生成同名材料表，并沿用当前搜索和分类筛选条件。

导出表格固定为 11 列：序号、组件类型、规格/NS、物料编码、材料描述、数量、单位、重量、归属、SKEY、管线号。管线号来自 IDF 的 `-6` 记录，并支持 `-1` 溢出续行。

材料汇总以“物料编码 + 材料描述 + 规格/NS + 单位 + SKEY + 管线号”作为合并条件。六项全部相同才累加数量；任一不同都会生成新的材料行。因此不同 SKEY 不会合并，每个管线号的材料也会分别统计。

## 解析规则

- 支持 Alias ISOGEN IDF 2005 文档中的组件类型 30–161。
- 内置 ISOGEN Symbol Key Reference Guide 2012 R2 的 392 条 SKEY 定义；组件名称优先按完整 SKEY、PCF Identification、IDF Record 和通配 SKEY 联合判断，未匹配时才回退到 IDF 类型号。焊接方式只作为名称修饰，不再把 Sockolet、Weldolet、管嘴或连接件误判为焊缝。
- 组件字段 9 关联文件底部按出现顺序排列的 `-20` 物料编码，`-21` 作为材料描述，`-80` 至 `-89` 作为补充描述。
- 支持 `-1` 溢出续行：可连续拼接物料编码、材料描述和补充描述；断在单词中间时不会误加空格。
- 只有普通管道类型 `100` 根据起点、终点坐标计算长度；坐标单位按规范除以 100 转为 mm，材料表以 m 汇总。类型 `101` 定长管和 `102/103` 管块均按件计。
- 多腿组件只统计主记录一次：例如弯管 `30/31`、三通 `45/46/47`、四通 `50/51/52/53`、多通阀和仪表的后续腿记录不重复增加材料数量。
- 根据各组件起点和终点坐标建立连接拓扑；非管道类组件连接到不同规格时，材料表规格自动写为 `DN大径×小径`。管道、垫片、螺栓、焊缝、支架及附加材料不参与异径判定。
- 其余组件按件汇总。
- 物料指针为 `0` 的组件不进入材料表。
- 复合字段 9 按规范从右向左解析：最低三位为物料指针，第 4–6 位为补强板指针，第 7–9 位为重复件编号。
- 字段 11 的 Millions 位为 `0` 或 `2` 时进入材料表；Millions 位为 `1` 时排除。
- 字段 14 的个位用于区分未分类、制作、安装与海工材料。
- 字段 14 个位仅定义 `0=未分类、1=制作、2=安装、3=海工`；其他代码按“未分类”显示，并在解析详情中报告异常数量。
- 公称直径自动推断公制或英制；原始数据始终保留在解析结果中。

## 示例

可用 `sample/demo.idf` 验证：应识别 8 条有效组件、排除 1 条不进入 BOM 的弯头，并得到 9 m 管道总长。

## 隐私

文件只在浏览器内存中读取，不会上传到服务器。
